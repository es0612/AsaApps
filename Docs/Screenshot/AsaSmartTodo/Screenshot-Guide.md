**撮影内容**: AI優先度予測バッジ付きのタスクリスト

**撮影手順**:
1. AsaSmartTodoアプリを起動
2. タスクリストビューを表示
3. 3〜5個のタスクが表示されている状態
4. 各タスクにAI予測バッジ（🤖 高、🤖 中、🤖 低）が表示されていることを確認

**撮影デバイス**: iPhone 16 Simulator（推奨）

### 2. AddTask.png - タスク作成画面
**撮影内容**: リアルタイムAI予測カード表示中のタスク作成画面

**撮影手順**:
1. タスクリストから「新しいタスク」ボタンをタップ
2. タイトルフィールドに「重要な会議の準備」と入力
3. 説明フィールドに「プレゼン資料を明日までに完成させる」と入力
4. カテゴリを「仕事」に設定
5. 期限を明日の日付に設定
6. AI予測カードが表示されることを確認
7. スクリーンショット撮影

**期待される表示要素**:
- [ ] 入力済みのタイトルフィールド
- [ ] 入力済みの説明フィールド
- [ ] カテゴリピッカー（「仕事」選択済み）
- [ ] 期限DatePicker（明日の日付設定済み）
- [ ] **AI予測カード**（推奨優先度: 高、信頼度: 85%等）
- [ ] 「採用」「無視」ボタン
- [ ] 「保存」ボタン

**撮影デバイス**: iPhone 16 Simulator（推奨）

---

### 3. Analytics.png - 分析画面
**撮影内容**: 週間チャートとトレンド表示

**撮影手順**:
1. タブバーから「分析」タブをタップ
2. 週間サマリーカードが表示されることを確認
   - 週間完了率
   - AI採用率
   - 朝活スコア
   - 平均信頼度
3. 24時間チャートが表示されることを確認
4. 週間トレンドチャートが表示されることを確認
5. スクリーンショット撮影（必要に応じて下にスクロールして全体を撮影）

**期待される表示要素**:
- [ ] 週間サマリーカード（4指標）
- [ ] 24時間チャート（タスク作成・完了のバーチャート）
- [ ] 週間トレンドチャート（完了率・AI採用率の折れ線グラフ）
- [ ] AI精度トレンド（信頼度推移）
- [ ] 期間選択ピッカー（週間/月間）

**撮影デバイス**: iPhone 16 Simulator（推奨）

**注意**: データがない場合は、事前にダミータスクを作成・完了しておく

### 4. Settings.png - 設定画面
**撮影内容**: AI重みカスタマイズスライダー表示

**撮影手順**:
1. タブバーから「設定」タブをタップ
2. 「AI予測の重み設定」セクションが表示されることを確認

5. 「重みをリセット」ボタンが表示されることを確認
6. スクリーンショット撮影

**期待される表示要素**:

## 🎬 撮影のコツ

1. **ライトモード推奨**: スクリーンショットはライトモードで撮影すると見やすい
2. **時刻統一**: すべてのスクリーンショットを同じ時刻（例: 10:00）で撮影すると統一感が出る
3. **バッテリー**: 100%表示が望ましい（シミュレータは常に100%）
4. **通知**: 不要な通知が表示されないよう、Do Not Disturbを有効化
5. **データ準備**: Analytics画面は事前にダミーデータを作成しておく
