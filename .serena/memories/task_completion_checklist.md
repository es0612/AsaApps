# タスク完了時のチェックリスト

## コード品質チェック

### 1. ビルドエラーの確認
```bash
# プロジェクトのビルドを実行
xcodebuild -project [AppName].xcodeproj -scheme [AppName] build
```
- ビルドエラーがないことを確認
- 警告がある場合は可能な限り修正

### 2. テストの実行
```bash
# 単体テスト実行
xcodebuild test -project [AppName].xcodeproj -scheme [AppName] -destination "platform=iOS Simulator,name=iPhone 15"
```
- 既存のテストが通ることを確認
- 新機能にテストが必要な場合は追加

### 3. コードスタイルの確認
- AsaAppsの命名規約に従っているか
- 適切なMARKコメントが付いているか
- @Observableパターンを使用しているか（ViewModelの場合）
- ブランドカラーを正しく使用しているか

## 機能確認

### 4. UIの動作確認
- シミュレータで実際に動作確認
- ブランドガイドラインに沿ったデザインか
- AsaButton、AsaCardなど共有コンポーネントを活用しているか

### 5. データ永続化の確認
- UserDefaults または Swift Data が正しく動作するか
- アプリの再起動後もデータが保持されているか

## ドキュメント更新

### 6. 必要に応じてドキュメント更新
- 新機能がある場合、実装ノートを`Docs/Notes/`に追加
- スクリーンショットが必要な場合は`Docs/Screenshot/`に保存

## 最終チェック

### 7. プロジェクト全体の整合性
- 関連する他のアプリに影響がないか確認
- 共有コンポーネントを変更した場合は依存するアプリをテスト

### 8. コミット準備
- 変更したファイルのみをステージング
- 適切なコミットメッセージを作成
- 不要なファイル（.DS_Store など）が含まれていないか確認

## エラー対応

### ビルドエラーが発生した場合
1. エラーメッセージを詳細に確認
2. インポート文の不足がないか確認
3. 共有コンポーネントの参照が正しいか確認
4. プロジェクト設定でTargetが正しく設定されているか確認

### テスト失敗の場合
1. テストログを確認
2. 新機能がテストの前提条件を変更していないか確認
3. モックデータやテスト環境の設定を確認
