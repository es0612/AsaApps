# AsaSmartHome SNS宣伝動画の準備プラン

## Context

AsaSmartHomeアプリのSNS宣伝動画を撮影するにあたり、デモ映えするデータや設定の整備が必要かを検討する。現状のモックデータで十分か、追加が必要かを分析し、必要な改善を実施する。

## 現状分析

### 初期データの充実度

| 項目 | 数量 | 評価 |
|------|------|------|
| 部屋 | 6個 | ⚠️ キッチン・子供部屋にデバイスなし |
| デバイス | 13個 | ✅ 8種類の多彩なデバイスタイプ |
| シーン | 5個 | ⚠️ 全てプリセット、カスタムなし |
| お気に入り | 5個 | ✅ ダッシュボードに表示される |
| ON状態 | 7個 | ✅ ON/OFF混在で操作デモに最適 |

### デモで映える要素（現状OK）
- ダッシュボード: ステータスサマリー + お気に入りデバイス一覧
- デバイス操作: 照明の明るさ/色温度スライダー、エアコン温度調整
- シーン実行: 「おやすみ」「映画モード」等のワンタップ一括操作
- ダークテーマ: スマートホームアプリらしい洗練されたUI

### 改善すべき点
1. **キッチン・子供部屋が空っぽ** → 部屋タブを見せた時にスカスカ感
2. **カスタムシーンがない** → シーン作成フローの紹介ができない
3. **スケジュールが未投入** → 定義はあるが初期データに含まれていない

## 改善プラン

### Step 1: 空き部屋にデバイスを追加

**対象ファイル**: `Apps/AsaSmartHome/AsaSmartHome/Services/Mock/MockSmartHomeService.swift`

`setupInitialDataIfNeeded()` メソッドにデバイスを追加:

**キッチン（3台追加）:**
- キッチンライト (Light) - ON, 明るさ100%, 色温度5000K
- スマート冷蔵庫 (Thermostat) - ON, 温度3°C, 湿度40%
- キッチン換気扇 (AC) - OFF

**子供部屋（2台追加）:**
- おやすみライト (Light) - OFF, 明るさ30%, 色温度2700K（暖色）
- 子供部屋エアコン (AC) - OFF, 温度25°C, 自動モード

→ 合計デバイス数: 13 → **18台**（よりリアルなスマートホーム感）

### Step 2: カスタムシーンを1〜2個追加

同じく `setupInitialDataIfNeeded()` に追加:

**カスタムシーン案:**
- **「集中モード」** - 書斎ライト全開 + 他の部屋消灯 + テレビOFF
- **「お料理タイム」** - キッチンライトON + 換気扇ON + スピーカーON

→ プリセット5 + カスタム2 = **7シーン**（バリエーション豊富）

### Step 3: データリセット用の対応

現状、`setupInitialDataIfNeeded()` は「既存データがあればスキップ」する仕組み。
動画撮影前にフレッシュな状態にするため:

- 設定画面の「すべてのデータをリセット」ボタンでリセット → 再起動でデモデータ再投入
- 既存の仕組みでOK、追加実装不要

## 推奨デモフロー（撮影シナリオ）

```
1. アプリ起動 → ダッシュボード表示（1秒）
2. ステータスサマリーを見せる（デバイス18台、全てオンライン）
3. お気に入りの「リビング照明」をタップ → 詳細画面
4. 明るさスライダーを操作 → リアルタイム反映（2秒）
5. 戻る → 「部屋」タブ切替（部屋一覧、全室にデバイスあり）
6. 「シーン」タブ → 「映画モード」をタップ実行（1秒）
7. ダッシュボードに戻る → デバイス状態が変わっている
```

所要時間: 約15〜20秒（SNS向けショート動画に最適）

## 対象ファイル

- `Apps/AsaSmartHome/AsaSmartHome/Services/Mock/MockSmartHomeService.swift` - デバイス・シーンの初期データ追加

## 検証

1. 設定 →「すべてのデータをリセット」→ アプリ再起動
2. ダッシュボードに18台のデバイス表示を確認
3. 部屋タブで全6部屋にデバイスが表示されることを確認
4. シーンタブでプリセット5 + カスタム2 = 7シーン表示を確認
5. デバイス操作（電源ON/OFF、スライダー調整）が正常動作
6. シーン実行が正常動作
